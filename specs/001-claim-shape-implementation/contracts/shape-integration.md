# Shape Integration Contracts

Canonical source: `src/lab8/runtime.py`, `src/lab8/tools.py`, `src/lab8/handoff.py`,
`src/lab8/schemas.py`, and `docs/architecture.md`.

## Shared Read Tool Surface

| Tool | Input/behavior | Output/constraint |
|---|---|---|
| `get_claim_view` | SQLite connection and claim ID | `found`, claim ID and permitted claim view; never use a raw `SELECT *` for trace/context. |
| `lookup_order` | Connection, optional order ID, principal ID | Visibility and only the `ORDER_FIELDS` allowlist; ownership is checked. |
| `lookup_policy` | Connection | Policies current and effective on configured as-of date. |
| `get_clause` | Connection and clause ID | Clause plus current/effective metadata; callers must validate those fields. |
| `lookup_refund_history` | Connection, order ID, principal ID | Scoped refund count and total for reasoning; host still enforces the cap. |
| `compute_compensation` | Connection and allowlisted order view | Deterministic quote fields; this, not model output, is authoritative for money. |

Tool dispatch accounts tool calls/cost through `Budget`. Existing tool definitions and schemas are
read-only interfaces for this work.

## ReAct Interface

`runtime.run_react(conn, budget, *, observation, decide, max_steps=8, worker=False)` calls the
`decide(observation) -> action` function. An action is either `{"final": {...}}` or
`{"tool": name, "args": {...}}`. It returns a stopped reason, final result, and observation.
Dispatch rejects write tools, and worker mode rejects every tool outside `READONLY_TOOLS`.
Shape B MUST use no more than 8 steps. Do not alter runtime semantics as part of shape work.

## Handoff and Investigator Interface

`handoff.make_handoff(*, request_id, claim_id, task, facts, allowed_tools,
max_output_tokens=400)` returns a sanitized `handoff.v1` dictionary. Top-level keys are limited to
`contract_version`, `request_id`, `claim_id`, `principal_scope`, `task`, `facts`, `allowed_tools`,
and `max_output_tokens`. Facts are filtered to the declared fact allowlist. `allowed_tools` must
be a subset of `READONLY_TOOLS`; write tools are forbidden.

`runtime.run_readonly_investigators(conn, budget, handoff, principal_id)` consumes this handoff
and returns a reduced claim view and tool results. The investigator does not receive raw parent
context and cannot write. Shape C, not its investigator, decides whether and how to call the host.

## Host Refund Interface

`durability.issue_refund(conn, claim_id, proposed_vnd, *, crash_at=None)` receives the full quote
and returns a dictionary containing `ok`, `reason`, `effect`, and `conflict`. The host validates
claim/order scope, approval binding/status/expiry/amount, paid amount, and order-level remaining
entitlement; it commits the ledger and `refund_committed` audit transactionally. Rejected positive
quotes are audited as `policy_denied`. A retry with the same amount is idempotent; conflicting
amount is rejected without replacing the existing effect. `InjectedCrash` propagates at the
configured fault point.

## Test and Artifact Integration

- Keep student tests in owner-specific files under `src/tests/`; retain the existing test matrix
  as the shared acceptance oracle.
- SQLite stores are per trial/member; reuse a store only to test retry/resume.
- Generated traces/SQLite stores are temporary and not committed; prescribed reports are
  generated by one integration operator and never manually edited.
